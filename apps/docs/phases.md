## 🚦 Phase 1 MVP Build Priorities

Within **[Phase 1](file:///Users/shrid/sharity/apps/docs/phases/phase-1-mvp-trust-loop.md)**, implementation proceeds in 5 distinct technical priorities:

1. **Priority 1 — User Profiles & Sessions:** Complete Better-Auth integration and user profile management (`/my-sharity/profile`).
2. **Priority 2 — Project & Multi-Modal Needs Engine:** Guided proposal wizard and multi-modal needs classification (Money, Items, Volunteers, Skills).
3. **Priority 3 — Review Queue & Discovery Engine:** Admin proposal review interface (`/admin/reviews`), Explore page (`/explore`), and interactive Impact Map (`/map`).
4. **Priority 4 — Milestones, Escrow & Public Ledger:** Milestone budget allocation, payment checkout, creator evidence submission, admin verification (`/admin/milestones`), and Public Ledger timeline.
5. **Priority 5 — Impact Reports & Stories:** Automated public Impact Report generation and Completed Stories gallery (`/stories`).
