# Phase 3 — National Scaling & Governance

> **Status:** 📋 Planned  
> **Goal:** Expand Sharity into a trusted national network across India with reputation-weighted governance, CSR matching, and open impact data APIs.

---

## 1. Core Modules

### 1.1 Reputation-Weighted Governance
- [ ] Community verification consensus with fail-safe admin overrides.
- [ ] Verified Trust Badges for creators, reviewers, and repeat contributors.

### 1.2 Corporate & CSR Impact Matching
- [ ] Corporate CSR portals for co-funding verified community projects.
- [ ] Employee volunteering modules and corporate matching rules (e.g. 1:1 match).

### 1.3 Multilingual & Regionalization
- [ ] Multi-language UI translation (Hindi, Marathi, Kannada, Tamil, Telugu, Bengali).
- [ ] Regionalized moderation and local legal compliance helpers.

### 1.4 Open Impact Data API
- [ ] Public read-only API endpoints for auditable public ledger events.
- [ ] Export tools for civic researchers and urban planners.
